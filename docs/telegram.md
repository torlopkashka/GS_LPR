# Telegram-бот

## Что умеет

**Кнопки внизу экрана** (появляются после `/start`):

| Кнопка | Что делает |
|---|---|
| 🔓 Открыть ворота | подаёт команду на ворота и отвечает, прошла ли она |
| 📡 Статус | состояние сервера, агента ворот и камер, последний обрыв интернета, последний номер. Кнопка «🔄 Обновить» под ответом |
| 🕘 Последние проезды | последние 10 событий журнала |
| 📋 Номера | список разрешённых номеров со сроками |

**Команды:**

```
/add А123ВС77 Иванов            добавить номер (владелец необязателен)
/add А123ВС77 Гость до 31.12.2026   временный доступ до даты включительно
/del А123ВС77                   удалить номер
/status  /open  /last  /list  /help
```

**Уведомления:**
- ✅ проезд разрешён: фото, номер, владелец, камера;
- ⛔ неизвестный номер: фото и кнопки **«🔓 Открыть ворота»** (действует 15 минут) и
  **«➕ В список»**. Если один человек нажал «Открыть», остальным в чате придёт отметка, кто открыл;
- ⚠️ агент ворот не на связи дольше 30 с, то есть автоматическое открытие не работает;
- ⚠️ нет видео с камеры дольше 2 минут;
- ✅ когда агент или камера восстановились, с указанием длительности простоя;
- 🔌 **связь с объектом восстановлена**: отчёт, сколько не было интернета и сколько машин
  за это время проехало или получило отказ.

Команды и кнопки принимаются только из чатов, перечисленных в `TELEGRAM_CHAT_IDS`.
Остальным бот отвечает «Доступ запрещён» и сообщает их chat id. Так удобно узнать id нового
участника, чтобы добавить его.

## Как бот ведёт себя при отключении интернета

Бот работает на том же ПК, что и сервер. Поэтому, когда на объекте пропадает интернет:

1. **Ворота продолжают работать.** Распознавание, агент и реле работают по локальной сети.
   Пульты тоже работают.
2. **Бот не может ответить.** Если на «📡 Статус» ответа нет, значит на объекте нет интернета
   или выключен компьютер. Если ответ пришёл, в нём видно, на связи ли агент и камеры.
3. **Накопившиеся команды не выполняются.** Telegram хранит нажатия до суток и доставит их,
   когда связь появится. Бот не откроет ворота по «Открыть», нажатой час назад, а ответит,
   что команда устарела. Выполняются только свежие команды, не старше 2 минут
   (`max_command_age`).
4. **После восстановления связи** бот сам пришлёт отчёт об обрыве.
5. **Чтобы узнать об обрыве сразу, а не после него**, нужен внешний сторож (см. ниже).
   Сам бот на отключённом ПК сообщить об этом не может.

## Настройка бота

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot`, задайте имя. Полученный токен
   впишите в `.env`:
   ```
   TELEGRAM_TOKEN=1234567890:AA...
   ```
2. Узнайте свой chat id: напишите [@userinfobot](https://t.me/userinfobot) или, после шага 3,
   просто напишите своему боту, и он ответит «Доступ запрещён. Ваш chat id: …».
3. Впишите id в `.env` через запятую (свои, членов семьи, id группы):
   ```
   TELEGRAM_CHAT_IDS=123456789,987654321
   ```
   Для группы: добавьте бота в группу и отправьте в ней `/start@имя_вашего_бота`, бот ответит id группы
   (отрицательное число, например `-1001234567890`). Чтобы бот видел кнопки из меню в группе,
   у @BotFather выполните `/setprivacy` → Disable.
4. Примените настройки: `docker compose up -d`, затем отправьте боту `/start`.

## Внешний сторож: уведомление, когда объект пропал со связи

Бот на отключённом ПК не может сообщить, что пропал сам. Для этого нужен сторож
**снаружи объекта**. Сервер раз в минуту отправляет ему сигнал «я жив». Если сигналы
прекратились (пропал интернет, выключился ПК, завис Docker), сторож сам пишет в Telegram.

Поддерживаются два формата. Сервер определяет формат по адресу автоматически:

| Сторож | Где работает | Адрес в `HEALTHCHECK_URL` |
|---|---|---|
| **Uptime Kuma** на своём VPS (рекомендуется) | ваш сервер, не зависит от зарубежных сервисов | `http(s)://ваш-vps:3001/api/push/<токен>` |
| healthchecks.io (облако или свой сервер) | облако за рубежом, либо свой экземпляр | `https://hc-ping.com/<uuid>` |

### Вариант 1. Uptime Kuma на VPS

[Uptime Kuma](https://github.com/louislam/uptime-kuma) — бесплатная программа мониторинга с открытым кодом
и русским интерфейсом. Ставится одной командой, умеет уведомлять в Telegram.
Подойдёт VPS в дата-центре, который у вас уже есть: сторожу хватает 256 МБ памяти.

1. На VPS (нужен Docker: `curl -fsSL https://get.docker.com | sh`):
   ```bash
   docker run -d --restart=always -p 3001:3001 -v uptime-kuma:/app/data \
     --name uptime-kuma louislam/uptime-kuma:1
   ```
   Откройте `http://IP-VPS:3001` и создайте учётную запись администратора.
   Если зайти по HTTP небезопасно, закройте порт 3001 файрволом для всех, кроме вашего
   IP, и объекта (или поставьте перед ним HTTPS-прокси).
2. **Настройки → Уведомления → Настроить уведомление → Telegram.** Нужен токен бота:
   создайте у @BotFather отдельного бота «сторож» или используйте бота ворот. Chat ID
   Kuma поможет узнать кнопкой «Auto Get». Нажмите «Тест».
3. **Добавить монитор**:
   - Тип монитора: **Push**;
   - Название: «Ворота»;
   - Интервал сердцебиения: **60** секунд;
   - Повторы: **4**. Тревога придёт после ~5 минут тишины, короткие сбои её не вызовут;
   - включите созданное уведомление Telegram;
   - скопируйте **Push URL** вида `http://IP-VPS:3001/api/push/AbCdEf1234?status=up&msg=OK&ping=`.
4. Впишите его в `.env` на ПК у ворот (параметры после `?` можно оставить или убрать,
   сервер подставит свои):
   ```
   HEALTHCHECK_URL=http://IP-VPS:3001/api/push/AbCdEf1234
   ```
   и выполните `docker compose up -d`. Через минуту монитор в Kuma станет зелёным.

Сервер шлёт `status=up`, пока всё в порядке. Если агент ворот или камера пропали, он шлёт
`status=down` с описанием проблемы (например «агент ворот не на связи»), и Kuma
сразу присылает тревогу. На странице Kuma видна история доступности объекта: когда и
на сколько пропадала связь.

### Вариант 2. healthchecks.io

1. Зарегистрируйтесь на [healthchecks.io](https://healthchecks.io) и создайте проверку:
   **Period** 1 minute, **Grace Time** 5 minutes.
2. **Integrations → Telegram**: подключите свой Telegram или группу.
3. Скопируйте адрес проверки в `.env`: `HEALTHCHECK_URL=https://hc-ping.com/<uuid>` и выполните
   `docker compose up -d`.

healthchecks тоже можно поставить на свой VPS (образ `healthchecks/healthchecks`), но
Uptime Kuma проще в настройке.

### Кто о чём сообщит

| Что случилось | Кто сообщит |
|---|---|
| агент ворот не на связи / нет видео, интернет есть | бот ворот и сторож |
| пропал интернет на объекте, выключился ПК, завис Docker | сторож, через ~5 минут |
| интернет вернулся | бот ворот: отчёт об обрыве; сторож: «снова в сети» |

Если VPS находится в России, проверьте, что с него доступен `api.telegram.org`:
`curl -sI https://api.telegram.org`. Иначе сторож не сможет отправить уведомление.
